# Каталог нейросетей

Веб-приложение для поиска и сравнения нейросетей: каталог с категориями и тегами, отзывы пользователей с оценками и личный кабинет. Личный проект.

## Возможности

- Каталог нейросетей по категориям: текст, изображения, код, аудио и речь, видео
- Теги по группам: цена (бесплатно / платно / пробный период), доступность в России, особенности (API, мобильное приложение, веб-интерфейс)
- Карточка нейросети: описание, инструкция по регистрации и настройке, ссылки на сайт, API и GitHub, тарифы
- Сравнение нескольких нейросетей на одной странице
- Рейтинг и топ нейросетей по отзывам
- Отзывы с оценкой 1–5 и голосованием «полезно / не полезно»
- Регистрация и вход (Spring Security, BCrypt), проверка занятости логина и email «на лету»
- Личный кабинет: профиль, смена email и пароля
- Тёмная и светлая тема

## Технологии

- Java 17, Spring Boot 3.4
- Spring MVC, Spring Data JPA (Hibernate), Spring Security, Bean Validation
- PostgreSQL
- Thymeleaf, HTML/CSS, JavaScript
- Lombok, Maven

Отдельно сделана версия на MongoDB (с Python-скриптом миграции данных из PostgreSQL) и проведено нагрузочное сравнение производительности двух СУБД.

## Структура базы данных

| Таблица | Назначение |
|---|---|
| `categories` | категории нейросетей |
| `neuronets` | нейросети |
| `tag_groups`, `tags`, `neuronet_tags` | теги и их привязка к нейросетям |
| `users` | пользователи |
| `reviews` | отзывы с оценкой |
| `review_votes` | голоса за отзывы |

## Запуск

1. Создайте в PostgreSQL базу `CatologistNeuralNetworks` и выполните скрипты из папки `bd/`.
   `bd/cleanup_demo_data.sql` заполняет базу демонстрационными данными.
2. Укажите логин и пароль к БД в `src/main/resources/application.properties`.
3. Запустите приложение:
   ```bash
   mvn spring-boot:run
   ```
4. Откройте http://localhost:8081

Чтобы оставлять отзывы, зарегистрируйтесь на странице `/users/register`.
